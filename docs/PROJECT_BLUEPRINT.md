## Product vision

Build a mobile-first fashion storefront that behaves like a continuous editorial runway. The customer should feel one connected motion system as they scroll, while product discovery, size selection, cart access, and checkout remain easy to use.

The creative system is inspired by cinematic chaptering, large media, and repeated conversion opportunities. It should not copy Rockstar artwork, typography, characters, or interface details.

## Technical framework

- Next.js App Router
- React and TypeScript
- GSAP and ScrollTrigger
- Native CSS design system
- Shopify Storefront API
- Shopify hosted checkout
- Vercel deployment
- Open Graph and text-message link preview assets
- Favicon, app icon, and social profile set

## Motion principles

- Native scroll only
- Unified direction and timing
- Pinned runway on capable desktop devices
- Static or simplified mobile and reduced-motion alternatives
- No motion that interferes with buying controls
- No dependence on animation for access to content

## Development phases

### Phase 1 — Framework

Use the included site to establish layout, responsive behavior, motion language, mock catalog, cart preview, metadata, and brand assets.

### Phase 2 — Client content

Replace abstract media and concept products with approved photographs, video, product information, biography, contact information, and policies.

### Phase 3 — Shopify

Connect products, variants, inventory, Shopify cart, and hosted checkout.

### Phase 4 — Marketing infrastructure

Configure email capture, analytics, pixels, consent, UTM conventions, and social account URLs.

### Phase 5 — QA and launch

Test checkout, mobile performance, reduced motion, accessibility, link previews, analytics, policies, and account ownership before paid promotion.
